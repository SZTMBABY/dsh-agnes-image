# 使用

[English](usage.en.md) · [文档索引](index.md)

## Agent 工具

### agnes_generate_image

同步接口：一次调用拿到结果，返回保存到本地的绝对路径。

| 参数 | 说明 |
| --- | --- |
| `prompt` | 必填。用用户自己的说法写，中文可以用 |
| `size` | `1K` / `2K`（默认）/ `3K` / `4K`。也接受精确的 `WxH` 字符串 |
| `ratio` | `1:1`（默认）、`3:4`、`4:3`、`16:9`、`9:16`、`2:3`、`3:2`、`21:9` |
| `reference_images` | 参考图数组，公网 HTTPS URL 或 `data:image/...;base64` 字符串 |
| `count` | 1（默认）到 4，超范围会夹回区间内 |

给了参考图就是图生图或多图合成。不要再要求 img2img 标签，模型自己判断。参考图最多取 8 张。

### agnes_generate_video

异步任务：创建后轮询到渲染完成，再把 mp4 下载到工作区。一般一到三分钟。

| 参数 | 说明 |
| --- | --- |
| `prompt` | 必填。先写主体和场景，再写动作、镜头运动、风格和声音 |
| `mode` | `text`（默认，只用提示词）、`keyframe`（用首帧/尾帧）、`reference`（用参考图/音频） |
| `seconds` | 字符串 `"4"` 到 `"12"`，默认 `"5"` |
| `size` | `720P` / `1080P` / `1K` / `2K`。`agnes-video-2.5-flash` 只出 720P，传别的会被压到 720P |
| `aspect_ratio` | `16:9`（默认）、`9:16`、`1:1`、`4:3`、`3:4`、`21:9` |
| `first_frame` / `last_frame` | keyframe 模式用，公网 URL、`data:` URL 或本地路径 |
| `images` | reference 模式的参考图，flash 模型最多 5 张。提示词里用 `<Picture 1>`、`<Picture 2>` 引用 |
| `audios` | reference 模式的参考音频，flash 模型最多 3 段，每段 2–12 秒。用 `<Audio 1>` 引用 |
| `seed` | 可选整数，同一个 seed 结果更可复现 |

模式约束在本地先校验一遍，错误信息直接说缺什么：

- `keyframe` 至少要一张首帧或尾帧；同时给参考图/音频会被拒。
- `reference` 至少要一张参考图或一段音频；同时给首帧/尾帧会被拒。
- 参考素材可以是公网 HTTPS URL、`data:` URL 或本地文件路径。本地文件会自动内联成 `data:` URL，单个文件上限 15 MB。

工具超时设成 900000 毫秒（15 分钟）。免费队列偶尔满或限流，插件自己重试几次；重试完还是失败，错误里会提示过一分钟再试。

## 面板

侧边栏入口注册在 `sidebar.panellist`，id 是 `agnes-image`，order 60。点进去是整页面板，页签顺序：图片生成、视频生成、库、设置。

![图片生成页签](../screenshots/panel-images.png)

### 图片生成

提示词输入框，尺寸、比例、数量（1–4），以及参考图输入框——一行一个 URL 或 `data:` URL。提示词框旁边有优化按钮。

生成中显示不确定条纹进度条加已用秒数。图片接口没有百分比通道，所以这里不编数字。

### 视频生成

提示词、模式（text / keyframe / reference）、时长、分辨率、画幅，加上对应模式的首帧/尾帧或参考图/参考音频，还有一个随机种子输入框。

![视频生成页签](../screenshots/panel-video.png)

跑起来显示上游的真实百分比（0/10/70/100），配当前状态和已用秒数。如果这个百分比超过 12 秒没有变化，进度条换成流动条纹，文案变成「上游只报到 X%，仍在渲染 · 已用 N 秒」，把数字的来源写清楚，不假装它在动。上游跳到 70 或 100 时立刻切回真实填充。

关掉页面再回来不会丢任务：宿主把任务记在 `video-tasks.json` 里，连同每个任务的输出目录，回来接着轮询，mp4 只下载一次。

### 库

分段切换图片和视频，是小卡片网格。

![图片库](../screenshots/library-images.png)

![视频库](../screenshots/library-videos.png)

每张卡片默认带缩略图：图片 96×96，视频封面 160×90。折叠时只显示缩略图和文件名；点文件名或箭头展开，看提示词、尺寸、比例、时长、字节数和操作按钮（打开、在文件夹中显示、插入到会话、复制、删除）。展开和收起是 200 ms 的过渡。

缩略图 hover 放大 1.03× 并加一圈橙色描边，提示它可以双击。双击用系统默认程序打开文件：图片给看图工具，视频给默认播放器，等同于在资源管理器里双击。

面板里不播放视频。视频卡片折叠时也要有东西可看，但宿主不解码视频，所以封面是浏览器抓的一帧（见 [architecture.md](architecture.md)）。没有封面时卡片上的提示是 `暂无封面（双击可用默认播放器打开）`。

### 设置

![设置页签](../screenshots/panel-settings.png)

- API Key：password 输入框，另有清除按钮。
- 模型、默认尺寸、默认比例、输出目录（留空 = 当前会话工作区）。
- 两行 mono 提示：当前 key 的来源和掩码形式，以及数据目录的绝对路径。

没 key 时页签顶部是红色横幅，生成按钮禁用。

视频的默认值（模型、分辨率、画幅、时长、轮询参数）和优化器的 token/超时不在面板里，只能通过 Config 改，见 [configuration.md](configuration.md)。优化器的后端下拉框在提示词输入框旁边，切换会立刻写回设置并持久化。

## 提示词优化

两个提示词输入框（图片和视频）共用一个重写器，后端二选一。

| 后端 | 说明 |
| --- | --- |
| `agnes` | 用同一把面板 key 调 Agnes 免费文本模型，默认 `agnes-3.0-flash`，温度 0.7，`max_tokens` 900。免费档偶发 429/5xx，会退避重试 3 次（间隔 2 秒、4 秒） |
| `dsh` | 走当前 profile 自己的对话模型。不额外花钱，也不需要额外 key。profile 没配默认模型或宿主没有 LLM 服务时这一项不可用，面板把它禁用 |

输入超过 4000 字符直接报错，不会调上游。输出上限 1200 字符。图片和视频用的是两份不同的系统提示：图片版最多 90 词（约 120 个汉字）、一到三句；视频版最多 110 词（约 150 个汉字）、两到四句，要求单镜头、不要分镜。两份都要求只回提示词本身，不要引号、标签或解释，并且用输入的语言作答。

## 几个常用写法

```
用 agnes_generate_image 生成一张 16:9 的 2K 壁纸，傍晚的上海天际线
```

```
把这两张图合成为一张，比例 1:1：https://.../a.png  https://.../b.png
```

```
agnes_generate_video，reference 模式，参考图 https://.../cat.png，
提示词里写 <Picture 1>，8 秒，9:16
```

```
agnes_generate_video，keyframe 模式，first_frame 给本地这张，镜头缓慢推近，6 秒
```
